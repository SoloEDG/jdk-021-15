# 午市厨房

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查及生产构建：

```sh
npm run typecheck
npm run build
```

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。

## 火候系统

- **四档火力**：关火 / 低火（120℃）/ 中火（170℃，默认）/ 高火（220℃）。调档后锅温按
  一阶惯性指数趋近目标温度，不会瞬间跳变（`src/shared/catalog.ts` 中的热工参数）。
- **品质模型**（`src/features/kitchen/lib/heat.ts`）：品质由累计熟度与过热损伤共同决定，
  不再只看烹饪时长。熟度是锅温对时间的积分；锅温越过菜品损伤阈值后按二次曲线累计损伤，
  时蔬阈值最低、最怕持续高火；牛排在高火档可累计封边风味加分，鼓励“高火封边 → 低火熟成”。
- **离火余温**：起锅菜品带走当前锅温，在出餐台继续累计熟度与损伤并指数冷却；起锅 15 秒后
  再叠加装盘失温扣分，销售金额按上菜时的实际品质计算。
- **控火计划与预演**：烹饪中可编辑未来换挡点，预演从灶台当前真实状态出发做纯函数模拟，
  并与“维持当前火力”的基准对比。采用计划只替换未执行段，已积累的熟度 / 损伤不会回写；
  预演期间手动调火会清空计划，再次预演即按最新状态重算（预演与实盘逐 tick 一致）。
- **单次下锅菜**：不做任何调档，默认中火即可在参考时长附近获得高品质成品；精细控火可获得
  更高但可解释的收益（熟度分 − 损伤扣分 + 封边加分）。
- **暂停**：暂停冻结全部热工积分，计划换挡点使用绝对游戏时间，恢复后不漂移、不重放。
